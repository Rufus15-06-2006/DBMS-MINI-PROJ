# ER Diagram Notes

`ER_Diagram.png` is the diagram supplied by the project team for the report. It is kept as the primary presentation diagram.

The submitted diagram is a simplified/conceptual view. In particular, it does not show the `emergency_requests` relation, and it does not display every attribute, key, and foreign-key detail from the implemented schema.

For a fuller implementation-oriented view, see:

- `ER_Diagram_Detailed.png` — detailed relational diagram preserved from the source project archive.
- `ER_Diagram_Detailed.svg` — scalable version of that detailed diagram.
- `ER_Diagram_Detailed.dot` — Graphviz source for that detailed diagram.
- `../sql/schema.sql` — authoritative table definitions, keys, constraints, indexes, views, triggers, and procedures.

For schema-level accuracy, use `sql/schema.sql` as the source of truth. Do not infer that an omitted table is absent from the implementation.
