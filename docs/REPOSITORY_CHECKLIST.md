# Repository Submission Checklist

- [ ] Confirm `README.md` setup instructions on a clean machine.
- [ ] Confirm `npm test` passes.
- [ ] Confirm `npm run build` passes.
- [ ] Run MySQL schema and seed scripts on the evaluation machine.
- [ ] Seed MongoDB and complete the application integration checklist in `TESTING.md`.
- [ ] Replace the pending contribution entries in `CONTRIBUTIONS.md` with the actual work split.
- [ ] Confirm the report PDF and editable DOCX in `report/` are the final versions.
- [ ] Confirm screenshots and ER diagram are correctly displayed in GitHub.
- [ ] Confirm no `.env`, passwords, tokens, database dumps containing real data, `node_modules/`, or `.next/` files are committed.
- [ ] Add the teammate as a GitHub collaborator with Write access if both members need to push.
- [ ] Check the final repository URL and confirm both team members can clone it.
